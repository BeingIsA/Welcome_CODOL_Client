# 离线物品解锁器

运行 `outputs/item-unlocker/CODOL_ItemUnlocker.exe`，无需安装 Python 或 Excel。
工具内置终版 21,740 件物品的 ID、内部名称、中文名、品质、类型和分类。

1. 退出游戏，启动工具。存档自动定位为 `%APPDATA%\CODOL\data\accounts\local.sqlite3`。
2. 选择账号，按类型、分类筛选或搜索中文名、内部名称、ID；分页默认每页100条。
3. 点击上表物品加入下表。换页、筛选或搜索保留已选项，同一 ID 不重复添加。
4. 下表支持多选移除、清空。点击“全部解锁”后一次保存整批物品。
5. 重新启动游戏查看库存。

每件新物品授予一件；已拥有物品跳过，保留已有数量、余额、配装和其他字段。
货币保留 ID 15400、20000 不可解锁。缺失存档或没有授权状态的旧账号不会被自动重置。
解锁前用 SQLite 备份机制生成一致备份，位置为数据库旁的 `item-unlocker-backups`。
保存使用账号修订号检测冲突；失败时保留待解锁清单，整个保存事务回滚。
若要恢复备份，退出游戏和工具后再恢复数据库。

目录来自终版资源静态导出，并非实时商城清单；没有中文名的行保留为空。
工具只修改本地库存授权，不修改原生客户端、不解除物品本身的使用条件。

## 开发与打包

在项目根目录创建专用虚拟环境，并安装 `client/tools/requirements-item-unlocker.txt`。
设置 `PYTHONPATH=client/src` 后可运行 `python -m codol_rebuild.tools.item_unlocker.main`。
打包执行 `client/tools/package_item_unlocker.ps1`；脚本使用
`verification/client/workspaces/item-unlocker-py312/Scripts/python.exe`（Python 3.12），生成单文件无控制台 EXE。
正式测试为 `client/tests/test_item_unlocker.py`，测试数据使用临时数据库，不写真实账号。
